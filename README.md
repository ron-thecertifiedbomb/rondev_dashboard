RonDevSolutions Dashboard

A clean and minimal Next.js + TypeScript dashboard built for personal use, experiments, and future internal tools under the RonDevSolutions brand.

This project uses the latest Next.js App Router and is structured for scalability, making it easy to extend with authentication, admin pages, widgets, or API routes.

📦 Tech Stack

Next.js 14+

React 18

TypeScript

Tailwind CSS (if installed)

ESLint + Prettier setup

📁 Project Structure

Reflects your actual files:

rondevsolutions-dashboard/
│── app/                   # Next.js App Router pages & layouts
│── public/                # Static assets
│── next.config.ts         # Next.js configuration
│── tsconfig.json          # TypeScript settings
│── eslint.config.mjs      # ESLint configuration
│── postcss.config.mjs     # PostCSS config (used by Tailwind)
│── next-env.d.ts          # Next.js TS environment types
│── package.json
│── README.md

🚀 Getting Started
1. Clone the repo
git clone https://github.com/ron-thecertifiedbomb/rondev_dashboard.git
cd rondevsolutions-dashboard

2. Install dependencies
npm install
# or yarn
# or pnpm

3. Start the development server
npm run dev


Open your browser:
👉 http://localhost:3000
